## 1. 종목 선택
   - 5종목 정도
   - TQQQ, SOXL, KORU 등

## 2. 종목별 금액 할당 및 분할
   - 1회당 최소 2주는 살 수 있는 금액
   - 20/30/40회 등 (40회가 기본)

## 3. 용어

### T
`T = 매수누적액 / 1회매수액`
- `1회매수액`은 **현재 회당금액**이다. 반복리·복리에서는 수익이 날 때마다 회당금액이 갱신되므로 T의 분모도 매일 바뀐다.


### 별지점
매수와 매도를 가르는 기준점. 분할횟수에 따라서 T가중치가 달라진다.
T가 분할횟수의 절반인 경우 별지점은 정확히 평단과 같아진다.

**일반 공식** (모든 분할수에 적용):

```
별지점 = 평단 * (1 + base * (1 - 2T/분할) / 100)
  base = 종목별 최대 괴리율(%포인트, 0.15가 아니라 15)
  TQQQ: base = 15
  SOXL: base = 20
```

- `T = 0`이면 `평단 * (1 + base%)`, `T = 분할/2`이면 정확히 `평단`이 된다.
- 40분할 검산: TQQQ `15·(1 - 2T/40) = 15 - 0.75T`, SOXL `20·(1 - 2T/40) = 20 - T`.

| 종목 | 40분할 식                 |
| ---- | ------------------------- |
| TQQQ | `평단*(1+(15-0.75T)/100)` |
| SOXL | `평단*(1+(20-T)/100)`     |

회차가 작을 때는 매수, 매도 모두 상대적으로 높은 금액으로 이루어지고, 회차가 클수록 매수, 매도 모두 상대적으로 낮은 금액으로 이루어진다. 
회차가 커질 수록 비중이 커지기 때문에 물타기가 잘 안된다. 그래서 수익권이 아니더라도 비중을 덜어내고 평단보다 낮은 금액으로만 매수한다.
그래야 탈출 가능성이 높아진다. 

매일매일 별지점을 계산해서 매수와 매도를 결정한다.

## 4. 매수
- **회당금액**
  - **단리, 반복리, 복리**를 선택한다. 수익이 생길 때마다 **할당금액에 수익(의 일부)을 더하고** 회당금액을 `할당금액/분할수`로 다시 계산한다.
    - **단리**: 기본 매수액 고정
    - **반복리**(기본): 할당금액 + `수익/2` → 회당금액 + `수익/2/분할수`
    - **복리**: 할당금액 + `수익` → 회당금액 + `수익/분할수` (차라리 VR에 넣는 걸 추천)
    - 예) 할당금액 1만불·40분할(회당 250불)에서 수익 80불이 난 경우 할당금액은 10,040불, 회당금액은 251불이 된다. 그 상태에서 또 80불의 수익이 난 경우 10,080불·252불이 된다.
    - 손실이 나도 할당금액·회당금액을 줄이지는 않는다 (증가 전용).
    - 따라서 **유효 할당금액 = 회당금액 × 분할수** 불변식이 항상 성립하고, 회차 소진 판정(§5)도 config의 초기 할당금액이 아니라 이 값을 기준으로 한다 (`매수누적액 + 회당금액 <= 회당금액 × 분할수`, 즉 T <= 분할수-1이면 매수 가능).

- **첫 매수**:
  - 할당금액의 2.5%(1/40)로 `전일 종가 * 1.1 ~ 1.15로 LOC매수`. 일단 진입해야 하기 때문에 널널하게 잡는다. + **여유매수**
  - **여유매수**: 
    1회매수금이 250불(`할당금액 1만불/40`)이고, 목표매수가는 `50불(전일종가)*1.15=57.5불`이다. 57.5불로 총 4개의 수량을 LOC매수 걸어두면 된다.     
    (1.15로 매수를 걸었는데 1.15이상으로 마감될 경우 매수되지 않을 수 있다.)
    만약 가격이 많이 빠진 경우, 예를들어 갑자기 40불로 마감된 경우 1회매수금으로 6개를 매수할 수 있는데 우리는 4개만 걸어뒀기 때문에 4개 밖에 매수되지 않는다. 
    1회매수금을 최대한 사용하기 위해서 추가로 매수를 더 걸어둔다. 
   
| 1회매수금 | 목표매수가 | 수량 | 설명                                         |
| --------: | ---------: | ---: | -------------------------------------------- |
|      $250 |      $57.5 |    4 |                                              |
|           |        $50 |    1 | 종가가 $50 아래인 경우 총 5개가 매수된다.    |
|           |     $41.66 |    1 | 종가가 $41.66 아래인 경우 총 6개가 매수된다. |

### **전반전(T < 분할/2 미만)**

- **별지점매수**와 **평단매수** 두 가지를 LOC로 건다.
  - **별지점매수**는 회당금액의 절반 어치를 별지점에 건다.
  - **평단매수**는 종가가 평단까지 빠질 경우 회당금액을 꽉 채우도록, 나머지 수량을 평단에 건다.
  - 따라서 종가가 별지점~평단 사이면 별지점매수만(회당금액 절반 수량), 평단 이하로 빠지면 둘 다 체결된다.
  - 단, LOC는 **종가로 체결**되므로 실제 소진 금액은 주문 수량 × 종가다. 종가가 평단보다 낮을수록 회당금액보다 적게 쓰인다. (예산을 더 채우려면 §4 첫 매수처럼 여유매수 단을 추가해야 한다.)
1. **별지점매수**: 목표가=`별지점-0.01`, 수량=`floor(회당금액/2/목표가)`가격으로 LOC매수. (매도와 겹치지 않기 위해서 `-0.01`)
      
| 목표가      | 수량                       |
| ----------- | -------------------------- |
| 별지점-0.01 | `floor(회당금액/2/목표가)` |

2. **평단매수** + 추가로 **여유매수**
           
| 목표가 | 수량                                     |
| ------ | ---------------------------------------- |
| 평단   | `floor(회당금액/평단) - 별지점매수 수량` |
 
### **후반전(T >= 분할/2 이상)**

- 전반전과 달리 절반으로 나누지 않고, 회당금액 전체를 **별지점매수**에 쓰고 부족분은 **여유매수**로 더 낮은 가격에 채운다.

| 목표가      | 수량                     |
| ----------- | ------------------------ |
| 별지점-0.01 | `floor(회당금액/목표가)` |

여유매수는 §4 첫 매수처럼 목표가보다 낮은 가격 단을 추가해 회당금액을 최대한 채운다.

매수되는 경우 T는 상승한다.

## 5. 매도

- 매일 전후반 상관없이 **쿼터매도** + **지정가매도**를 건다. (**AFTER 지정가** 매도를 사용한다.)
  - **쿼터매도**: 잔량의 25%를 **별지점매도**
    
| 목표가 | 수량            |
| ------ | --------------- |
| 별지점 | `floor(잔량/4)` |

  - **지정가매도**: 잔량의 75%를 종목에 따라 지정가매도. `SOXL은 평단+20%, TQQQ는 평단+15%`

| 목표가        | 수량                   |
| ------------- | ---------------------- |
| 평단*1.15~1.2 | `잔량 - 쿼터매도 수량` |

쿼터매도되는 경우 잔량의 25%(`floor(잔량/4)`)를 덜어내므로 매수누적액도 약 25% 줄고, 따라서 T는 약 `0.75배`로 하락한다. (회당금액 변동에 따른 T 변화는 별개다.) 지정가매도되어 보유 수량이 모두 청산되면 사이클이 끝나고, 다시 **첫 매수**(§4)부터 새 사이클을 시작한다.

### 회차를 모두 소진한 경우 (1회차 매수가 불가능한 상황)

**쿼터매도**실행

- **쿼터매도**: MOC매도로 잔량의 25%를 매도, 나머지 75%는 **지정가매도**. 쿼터매도한 날은 매수 X

쿼터매도 시 T가 줄어들기 때문에 다시 T에 맞춰서 매수,매도를 이어간다.
