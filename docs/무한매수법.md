1. 종목 선택
   - 5종목 정도
   - TQQQ, SOXL, KORU
2. 종목별 금액 할당
   - 1회당 최소 2주는 살 수 있는 금액
3. 종목별 금액 분할
   - 20/30/40회 등 (40회가 기본)
- *%: `평단*(1+(10-T/2)/100)`
  - **T**: 회차를 나타낸다. `round(매수누적액 / 1회매수액, 3)` 예) 4만불을 40분할 한 경우 1회매수액은 1000불. 첫날에 980불 매수한 경우, T는 980/1000 = 0.98
  - T=6으로 가정하면 `6/2=3 -> 10-3=7 -> 7/100=0.07 -> 1+0.07=1.07` 평단 * 1.07로 매수한다.
  - 회차가 작을 때는 매수, 매도 모두 상대적으로 높은 금액으로 이루어지고, 회차가 클수록 매수, 매도 모두 상대적으로 낮은 금액으로 이루어진다.
4. 매수
   1. 첫매수
      - loc로 정액매수. **RSI 60미만**에서 매수 추천
   2. 매수
      - 매일 1회치(40분할일 경우, 할당금액의 2.5%) 매수 주문을 걸어둔다. 할당 금액이 다 떨어질 때까지 반복한다. 
        하루에 1회치 금액이 모두, 절반만 또는, 사용되지 않을 수도 있다. 
      - 매수 방법
        - **전반전(20회차 미만)**
          1. 하루 매수액의 반은 **평단매수**
          2. 나머지는 `*%-0.01`가격으로 LOC매수. (매도와 겹치지 않기 위해서 `-0.01`)
        - **후반전(20회차 이상)**(할당 금액을 절반 소진한 경우)
          - 1회치를 `*%-0.01`로 LOC매수
   3. 매도
      - 매일 매도 주문을 건다. **AFTER 지정가** 매도를 사용한다.
      1. *%로 25% LOC매도
      2. 나머지 75%는 평단+10%로 지정가매도
      - 매도된 비중에 따라서 회차도 조절한다. 예) 30회차에서 +5%, +10%로 매도를 걸어서 +5%만 매도된 경우, 절반을 매도했기 때문에 회차도 15회차로 보고 다시 40회차까지 진행한다.
      - 40회차까지 다 매수했는데 매도되지 않은 경우, **쿼터손절**실행
        - **쿼터손절**: MOC매도로 잔량의 25%를 매도
        - 쿼터손절 후 생긴 현금으로 10회 분할해서 매매를 이어간다.
          - **매수**: -10% LOC 매수
          - **매도**: 25%는 -10% LOC매도, 75%는 평단*1.1 지정가매도
          - 10회를 모두 소진한 경우 다시 쿼터손절. 쿼터손절이 -10%이내인 경우 후반전으로 
          - 중간에 매도가 된 경우 후반전으로
