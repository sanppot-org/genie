1. 종목 선택
   - 5종목 정도
   - TQQQ, SOXL, KORU
2. 종목별 금액 할당
   - 1회당 최소 2주는 살 수 있는 금액
3. 종목별 금액 분할
   - 20/30/40회 등 (40회가 기본)
4. 매수
   1. 첫매수
      - loc로 정액매수. **RSI 60미만**에서 매수 추천
   2. 매수
      - 매일 1회치(40분할일 경우, 할당금액의 2.5%) 매수 주문을 걸어둔다. 할당 금액이 다 떨어질 때까지 반복한다. 
        하루에 1회치 금액이 모두, 절반만 또는, 사용되지 않을 수도 있다. 
      - 매수 종류
        - **LOC평단매수**: 평단가
        - **LOC큰수매수**: 현재가의 +10~15%. 최대값은 평단가의 +5%. `min(평단*1.05,현재가*1.15)`
          예를들어 평단이 100달러고 현재가가 105달러라면 큰수매수가는 105달러다. 다른 경우로 평단가는 100달러로 동일하고 현재가가 80달러라면 큰수매수가는 88~92(10~15%)달러다.
      - 매수 방법
        - **전반전(20회차 미만)**
          - 하루 매수액의 반은 **평단매수**, 나머지는 **큰수매수**
        - **후반전(20회차 이상)**(할당 금액을 절반 소진한 경우)
          - 1회치를 **평단매수**로 건다.
   3. 매도
      - 매일 매도 주문을 건다. **AFTER 지정가** 매도를 사용한다.
      - **전반전(20회차 미만)**:
        1. 평단 +5%로 25% **LOC매도**
        2. 평단 +10%로 75% 지정가매도
        - 25%, 100% 주문 
      - **후반전(20회차 이상)**: 
        1. 평단 +10%로 50% 지정가매도 
        2. 평단 +5%로 25% 지정가매도
        3. 평단으로 25% LOC매도 
        - 50%, 50%, 100% 주문
        - 매도된 비중에 따라서 회차도 조절한다. 예) 30회차에서 +5%, +10%로 매도를 걸어서 +5%만 매도된 경우, 절반을 매도했기 때문에 회차도 15회차로 보고 다시 40회차까지 진행한다.
      - 40회차까지 다 매수했는데 매도되지 않은 경우, **쿼터손절**실행
